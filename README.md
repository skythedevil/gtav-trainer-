# GTA V PS5 Menu Installer (Android)

Install the GronedWaffel GTA V Story Mode menu on your PS5 **from your phone**.
After installing, the menu runs inside the game. In GTA press **L1 + D-pad Right**.

## You need
- PS5 jailbroken on firmware 13.60 with **PS5Debug-NG 1.3.2** running
- GTA V (PPSA04263 01.000.000 or PPSA04264 01.010.002), loaded into **Story Mode**
- Phone and PS5 on the same Wi-Fi

## Get the APK (no coding)
1. Create a free account on github.com and make a **new repository** (private is fine).
2. Click **Add file → Upload files** and drag in everything inside this folder (including the hidden `.github` folder). Commit.
3. Open the **Actions** tab. The "Build APK" job runs by itself (about 5–10 minutes).
4. Open the finished run, download **GTA-V-PS5-Menu-apk**, unzip, and send `app-debug.apk` to your phone.
5. On the phone, open the file and allow "install from this source".

## Use it
1. Start PS5, jailbreak, PS5Debug-NG, then GTA V → Story Mode (unpaused).
2. In the app type your PS5's IP address (PS5: Settings → Network → View connection status).
3. Tap **Check connection** (changes nothing). If it says all good, tap **Install in-game menu**.
4. Press **L1 + D-pad Right** in GTA. Restart GTA = reinstall needed.

Controls: D-pad Up/Down move, Cross select, Circle back.
